## Журнал дебага и устранения ошибок (Troubleshooting)

### Ошибка авторизации: 401 Unauthorized
* **Симптомы:** Сбой аутентификации API, сервер возвращает статус 401.
* **Причина:** Невалидный токен в конфигурации `GIGACHAT_CREDENTIALS` (лишние пробелы, кавычки, синтаксический мусор или устаревшие данные авторизации).
* **Фикс:** Проведена очистка переменных окружения. Внедрена Fault Tolerance архитектура: в случае повторения ошибки 401, скрипт бесшовно перенаправляет трафик на HuggingFace.

### Ошибка лимитов: 429 Too Many Requests
* **Симптомы:** Блокировка портов со стороны API-сервера, статус 429.
* **Причина:** Высокая частота отправки пакетов и превышение Rate Limits со стороны параллельных процессов.
* **Фикс:** В код добавлены таймауты между итерациями функций. Развернут резервный Fallback-маршрут через модели HuggingFace для сохранения аптайма системы при перегрузках основного шлюза.
